# Plugin Store promo images

Marketing images for the Vismaz listing on the Craft Plugin Store, rendered in the same theme as
the plugin's marketing page at
[justinholt.com/plugins/craft-vismaz](https://justinholt.com/plugins/craft-vismaz).

## Building

```bash
./build.sh          # all slides
./build.sh "2 5"    # just slides 2 and 5
```

Output lands in `out/` as `vismaz-promo-N.png`, 1920×1080 (rendered at 2× in headless Chrome, then
downsampled so the type stays crisp).

Chrome occasionally dies with a `Trace/BPT trap` partway through a full run. It is transient and
the script uses `set -e`, so re-run the slides it did not reach rather than assuming a real
failure.

## Slides

| # | Slide | Shows |
|---|-------|-------|
| 1 | Cover — name, tagline, app icon, price | — |
| 2 | `412 orders` → `1 verifikat` | the whole pitch, in one line |
| 3 | Knows where the sale is | four VAT treatments and the accounts they book to |
| 4 | Öresavrundning | 124,60 → 125,00 with 0,40 to 3740 |
| 5 | Balances, or it stays home | a real summary voucher, debit and credit |
| 6 | Cannot post it twice | the four steps of a safe send |
| 7 | Console & SIE | dry run and SIE export |

**The figures on slides 5 and 7 balance, and they have to.** This is a promo for a bookkeeping
plugin; a journal that does not add up is worse than no journal. The presented set is
504 655,80 + 7 685,10 debit against 409 872,00 + 102 468,00 + 0,90 credit — 512 340,90 each way,
with 102 468,00 being exactly 25 % of 409 872,00. Change one number and you change four.

## Editing

Everything lives in `slides.html` — one `<section class="slide">` per image. The palette and fonts
are the plugin site's: accent `#0f76b4`, Jersey 20 for display, Inter for body. The blue-and-gold
is Swedish-flag adjacent on purpose, and keeps the deck distinct from Abacus's green.

`assets/` holds the fonts and two icon files:

- `icon.svg` — the app icon, used for the cover mark and the footer lockup. Copy it from
  `../src/icon.svg` whenever the icon changes.
- `watermark.svg` — the ledger's interior rules only, **no page frame, as hairlines**. Two traps,
  both hit while building this: filled bars at watermark scale read as a row of hard-edged pills
  behind the type, and re-adding the page frame as an outline reads as a stray panel edge cutting
  across the composition. Thin strokes and no frame is what works. The cover suppresses the
  watermark entirely (`.cover::after { display: none }`) since it already shows the icon at 460px.

`fonts.css` is generated by `build.sh` (the woff2 files are base64-inlined so Chrome's `file://`
origin rules can't block them) and is not checked in.
